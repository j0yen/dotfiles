# Mechanisms (a rule ships as code; each line names the file, the test and the failure it stops)

- **D1 follow-up owed ids at SessionStart + every seat-tick prompt** — `.claude/hooks/seat-context-start.sh` (`fu_print`), `.local/bin/seat-tick.sh` (FU_LINE), `.claude/hooks/followup-lib.sh`; prints `FOLLOW-UPS OWED (seat <s>): N owed, M overdue: <id> <age>h <state>, …` (10 ids, "and K more") from `wm-decide followups --json --agent <s>`; `follow-ups: unmeasured (<reason>)` when the tracker is absent; test `tests/followup-hooks.test.sh` (a, d). Stops: a counter nobody reads (approvals #114).
- **D2 Stop gate: an overdue/escalated follow-up id must be cited or cleared** — `.claude/hooks/followup-stop-gate.sh` (Stop, seats rb/r7/ctl/aide by WM_SEAT; plain sessions untouched); refuses at most 2 times per turn, then allows and logs `FOLLOWUP-STOP-OVERRIDE`; fail-open + `FOLLOWUP-STOP-ALLOW unmeasured` when the tracker fails; fires log `~/.local/state/followup-stop-gate/fires.log` (`FOLLOWUP_STOP_FIRES_LOG`); test `tests/followup-hooks.test.sh` (b–e, g).
- **E ctl Stop gate covers every seat's overdue ids** — same hook, seat `ctl` reads `wm-decide followups --json` with no `--agent`, so the controller cannot end a sweep without a row or text citing another seat's overdue id; test `tests/followup-hooks.test.sh` (f).
